# 닉네임 점수 최고 콤보 회피율 랭크 포인트 관리

튜토리얼 관리

목록 조회는 GET /api/tutorials를 사용합니다. 튜토리얼 추가/수정/삭제는 POST /api/admin/tutorials 관리자 API가 있어야 동작합니다.
새 튜토리얼 추가
저장은 POST /api/admin/tutorials 엔드포인트를 사용합니다. 백엔드 라우터가 없으면 콘솔 오류가 표시됩니다.
ID 제목 난이도 프리미엄 EXP 코인 순서 관리

스파링 영상 관리

목록 조회는 GET /api/videos를 사용합니다. 영상 추가/삭제/타임스탬프 관리는 POST /api/admin/videos 관리자 API가 있어야 동작합니다.
새 스파링 영상 추가
필수 입력값은 impact_time, dodge_window_ms, attack_type입니다. 나머지 항목은 스파링 판정을 더 세밀하게 조절할 때 사용하는 선택값입니다.
ID 제목 공격 타입 난이도 길이(초) 타임스탬프 프리미엄 관리
