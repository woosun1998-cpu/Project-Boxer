# BOXER V2 다음 작업 계획

작성일: 2026-04-21

## 1. 다음 작업 방향
- 대시보드와 샵 페이지의 상단 여백, 카드 간격, 타이포그래피를 더 미세하게 통일한다.
- 로그인 이후 사용자 이름 표시가 모든 페이지에서 자연스럽게 보이도록 점검한다.
- 공통 네비게이션의 브랜드/메뉴/칩 스타일을 페이지별로 더 일관되게 맞춘다.

## 2. 우선순위 작업

### 2-1. 대시보드 추가 다듬기
- `Boxer Quote` 문구의 길이와 속도를 더 자연스럽게 조정한다.
- `YOU / COACH` 카드 비율과 중앙 `VS`의 크기를 필요 시 한 번 더 미세 조정한다.
- 상단 환영 문구와 명언, 보드 사이의 간격을 점검한다.

### 2-2. 샵 페이지 추가 다듬기
- `SHOP` 히어로 영역의 명암과 텍스트 배치를 대시보드 톤에 더 가깝게 맞춘다.
- 플랜 카드와 상단 히어로 사이의 시선 흐름을 더 정리한다.

### 2-3. 로그인/사용자 정보 확장
- 로그인 후 사용자 이름 외에 코인/등급 정보도 더 잘 보이게 만들 수 있는지 검토한다.
- `Guest` 상태와 로그인 상태의 시각 차이를 더 분명하게 만든다.

## 3. 점검할 파일

- 다음 작업은 큰 구조 변경보다 디테일 조정 위주로 가는 것이 좋다.
