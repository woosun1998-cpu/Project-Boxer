# BOXER V2 오늘 작업 정리

작성일: 2026-04-22

## 1. 오늘 작업 요약
- `sparring-1.html`의 깨진 문구와 일부 깨진 마크업을 정리해서 페이지가 다시 정상적으로 열리도록 복구했다.
- 스파링 화면의 초급, 중급, 상급, 프로급 라벨과 경기 안내 문구를 한글/영어로 다시 정리했다.
- 반격 카운터, KO 연출, 데모 오버레이, 상태 바, 디버그 패널 문구를 정리했다.
- `sparring`에서 초급/중급/상급/프로 난이도 선택 흐름과 계정 배지 표시를 정리했다.
- 튜토리얼과 자세 교정 페이지의 모델 경로와 펀치 라벨을 `jab / cross / hook / uppercut` 기준으로 맞췄다.

## 2. Sparring 화면 정리
- `frontend/sparring-1.html`의 깨진 문자열을 다수 복구했다.
- 시작 화면의 난이도 버튼을 `초급 / 중급 / 상급 / 프로급`으로 다시 표시했다.
- 경기 안내 모달의 제목, 설명, 버튼 문구를 정상 문장으로 정리했다.
- HUD와 상태 바의 `반응 속도`, `획득 점수`, `회피 방향`, `회피율`, `판정 결과` 문구를 다시 맞췄다.
- KO 화면의 코너 멘트와 결과 카드 문구를 한글로 정리했다.
- 데모 오버레이 문구를 `데모 영상이 자동 재생됩니다.`, `카운트다운이 끝나면 경기 시작됩니다.`로 바꿨다.
- `일시정지 / 재개 / 종료 / 다시 시작 / 대시보드 / 상점` 버튼 문구를 정리했다.

## 3. 반격 / 판정 흐름
- 초급 2, 3에서 `DODGE` 이후 반격 창이 열리고 반격 성공 시 `COUNTER`가 저장되도록 유지했다.
- 반격 성공 문구를 `2차 반격 준비`, `반격!`, `COUNTER JAB / COUNTER HOOK / COUNTER UPPERCUT`로 정리했다.
- KO 연출은 화면 흔들림, 붉은 글로우, 카운트다운 숫자, 결과 카드 흐름을 유지했다.
- 반격 슬로모션은 짧게 유지해서 게임 타격감을 살렸다.

## 4. Backend / DB
- 초급 스파링용 영상과 timestamps를 DB에 맞췄다.
- 중급, 상급, 프로용 스파링 영상과 timestamps도 보강했다.
- 테스트용으로 고급/프로 난이도 개방 SQL과 원복 SQL을 준비했다.
- `sparring` 시작 화면에 계정 배지와 스킬 배지를 노출하도록 정리했다.
- 프리미엄/티어 기반 잠금 로직은 정리하고, 로그인 후 난이도 선택이 자연스럽게 보이도록 맞췄다.

## 5. Tutorial / 자세 교정
- `Boxing_ai_web_model`을 `/static/boxing_ai_web_model/model.json`으로 읽도록 연결했다.
- 튜토리얼의 감지 라벨을 `jab / cross / hook / uppercut` 기준으로 바꿨다.
- 튜토리얼 화면에서 펀치별 색과 효과를 분리했다.
- 자세 교정 페이지도 `JAB / CROSS / HOOK / UPPERCUT DETECTOR` 기준으로 다시 정리했다.

## 6. 모델 / 데이터셋 정리
- `jab`과 `cross`가 약한 이유를 데이터셋 쪽에서 점검했다.
- Roboflow 재학습용 기준을 정리했다.
- 클래스별 최소 샘플 수, 라벨링 규칙, export 절차, `data.yaml`, `labels` 배열 순서를 정리했다.
- 현재 프로젝트의 `labels` 순서는 `hook / uppercut / cross / jab / No punch`로 유지하는 방향을 잡았다.

## 7. 검증
- `frontend/sparring-1.html`의 script 블록 파싱을 다시 확인했다.
- `http://localhost:5500/sparring-1.html`과 `http://127.0.0.1:8000/api/health` 응답을 확인했다.
- 프런트 서버와 백엔드 서버를 다시 올려서 동작 상태를 복구했다.

## 8. 앞으로 할 일
- `sparring` 화면에서 남아 있는 자잘한 깨진 문구를 추가로 정리한다.
- `jab / cross` 감지 정확도를 높이기 위해 Roboflow 재학습 데이터를 더 보강한다.
- 필요하면 KO 화면과 카운터 연출을 더 게임답게 다듬는다.
- 중급, 상급, 프로 난이도의 점수 반영과 timestamps를 계속 테스트한다.
