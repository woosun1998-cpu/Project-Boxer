# Sparring Beginner Counter Design

## 방향

- 초급 1은 현재처럼 `DODGE` 중심으로 유지한다.
- 초급 2부터는 `DODGE` 성공 뒤 짧은 반격 창을 연다.
- 초급 3은 `DODGE + COUNTER` 콤보를 요구해서 리듬감을 만든다.
- 이후 Roboflow 모델로 `jab / hook / uppercut` 감지를 붙인다.

## 추천 진행 방식

### 1. 초급 1: 회피만 익히기

- 목표는 피하는 타이밍을 익히는 것.
- 점수는 `DODGE` 성공에만 준다.
- 실패하면 HP만 감소한다.

### 2. 초급 2: 회피 후 반격

- 공격이 지나간 직후 `counter window`를 연다.
- 이때 사용자는 짧은 반격 동작을 넣는다.
- 반격 성공 시 추가 점수를 준다.

### 3. 초급 3: 회피 + 반격 콤보

- `DODGE` 성공 후 1차 반격.
- 이어서 2차 반격까지 성공하면 콤보 보너스.
- 실패하면 반격 보너스만 놓치고, 회피 점수는 유지할 수 있다.

## 현재 코드에 넣을 최소 구조

- `pendingJudge` 이후 `counterJudge`를 추가한다.
- `DODGE` 성공 시 `counterWindowActive = true`로 바꾼다.
- `counterWindowMs` 동안 사용자의 반격을 판정한다.
- 반격 성공 결과는 `COUNTER_SUCCESS`로 저장한다.

## 점수 구조

- `DODGE` 점수
- `COUNTER` 추가 점수
- 연속 성공 시 `combo` 보너스
- 초급 3은 `dodge + counter + counter` 같은 짧은 연속 패턴이 가능하다.

### 추천 점수 산식

- `DODGE` 기본점수: `90`
- 반격 기본점수: `40`
- 첫 반격 성공 보너스: `+20`
- 연속 반격 보너스: `+10`
- 타이밍이 좋으면 최대 `1.3x`
- 늦은 반격이면 `0.8x`

예시:

- `DODGE` 성공 후 바로 반격 성공: `90 + 40 + 보너스`
- `DODGE` 성공 후 첫 반격 실패: `90`만 획득
- 초급 3에서 `DODGE + COUNTER + COUNTER` 성공: `90 + 40 + 40 + 콤보 보너스`

## 반격 판정 방식

### 단기

- Roboflow 없이 포즈 기반 규칙으로 시작한다.
- 예시:
  - 앞손이 전진하면 `jab`
  - 몸통 회전이 크면 `hook`
  - 위로 치솟는 궤적이면 `uppercut`

  - 가장 쉬운 MVP

- 공격 회피 성공 시 1초 안에
- 왼손이 앞으로 뻗으면 jab
- 오른손이 앞으로 강하게 나오면 cross
- 손이 위로 말리면 uppercut
- 몸통 회전이 크면 hook

### 장기

- Roboflow로 펀치 분류 모델을 분리한다.
- 라벨은 `jab`, `hook`, `uppercut`로 확장한다.
- 회피 판정과 펀치 분류를 분리해서 유지한다.

## 구현 순서

1. 초급 1은 현재 상태 유지
2. 초급 2에 `counter window` 추가
3. 초급 3에 연속 반격 추가
4. 반격 점수와 UI 표시 추가
5. Roboflow 모델 교체로 펀치 분류 확장

## 반격 타이밍 규칙

### 초급 2

- `DODGE` 성공 직후 `450ms ~ 900ms` 안에 반격 입력을 받는다.
- 너무 빠른 입력은 선입력으로 보고 무효 처리한다.
- 너무 늦은 입력은 `counter miss`로 처리한다.
- 추천 기준:
  - `counterOpenMs = 450`
  - `counterCloseMs = 900`

### 초급 3

- `DODGE` 성공 직후 1차 반격 창을 연다.
- 1차 반격 성공 후 `300ms ~ 700ms` 안에 2차 반격 창을 연다.
- 2단 콤보가 되려면 두 번 모두 타이밍 안에 들어와야 한다.
- 추천 기준:
  - `counterOpenMs = 400`
  - `counterCloseMs = 850`
  - `comboFollowUpMs = 300 ~ 700`

### 판정 원칙

- 회피 판정과 반격 판정은 분리한다.
- 회피는 회피대로 점수화한다.
- 반격은 반격대로 추가 점수화한다.
- 회피 성공이 반격 실패로 취소되면 안 된다.
- 반격 성공이 회피 실패를 보상하면 안 된다.

## 꼭 확인할 것

- 회피 성공과 반격 성공을 분리해서 저장한다.
- 반격 실패가 회피 성공까지 무효화하지 않게 한다.
- 초급 화면에는 `지금은 피하기`, `지금은 반격` 같은 짧은 안내를 넣는다.
- 모델 확장 전까지는 반격을 포즈 규칙으로 먼저 검증한다.
