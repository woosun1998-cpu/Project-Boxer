# 02. 복서 프로젝트 실행/테스트 체크리스트

## 01) 서버 실행 체크
- [ ] 백엔드 실행: `backend` 폴더에서 `py -m uvicorn main:app --reload --port 8000`
- [ ] 프론트 실행: `frontend` 폴더에서 `py -m http.server 5500`
- [ ] 브라우저 접속: `http://localhost:5500/index.html`

## 02) 다이어트 복싱 탭 이동 체크
- [ ] 상단 메뉴에서 `다이어트 복싱` 탭 클릭 가능
- [ ] `diet.html` 접속 시 404 없음
- [ ] 한글 깨짐 없음

## 03) 관리자 영상 등록 체크
- [ ] `admin.html` 접속
- [ ] `🥗 다이어트 영상` 탭 클릭 가능
- [ ] `+ 다이어트 영상 추가` 버튼 동작
- [ ] `📁 파일 선택` 클릭 후 파일 선택 가능
- [ ] 영상 제목/설명/경로 저장 성공 토스트 확인
- [ ] 등록 목록 테이블에 새 항목 표시

## 04) 사용자 영상 재생 체크
- [ ] `diet.html`에서 등록 영상 카드 표시
- [ ] 카드 클릭 시 플레이어 영역 열림
- [ ] 선택한 영상 재생 시작
- [ ] 재생 실패 시 경로 안내 토스트 표시

## 05) 목표/달성률 체크
- [ ] 목표 운동시간 입력 후 `목표 저장` 동작
- [ ] 목표 칼로리 입력 후 `목표 저장` 동작
- [ ] 목표 정확도 입력 후 `목표 저장` 동작
- [ ] 상단 목표 카드 값이 입력값으로 반영
- [ ] 달성률 진행바/퍼센트 갱신

## 06) 진행상황 보호 체크 (임의 수정 방지)
- [ ] 현재 수행치 3개 입력칸이 읽기 전용(`readonly`)인지 확인
- [ ] `진행 상황 저장` 버튼이 없는지 확인
- [ ] 사용자 수동 입력으로 수행치 변경이 불가능한지 확인

## 07) 캠 모드 측정 체크
- [ ] 영상 선택 전 `캠 모드 활성화` 시 에러 안내 정상 표시
- [ ] 영상 선택 후 `캠 모드 활성화` 가능
- [ ] 카메라 권한 요청 및 승인 동작
- [ ] `측정 종료` 버튼으로 종료 가능
- [ ] 세션 종료 후 시간/정확도/칼로리 저장 토스트 확인

## 08) MediaPipe + 튜토리얼 엔진 체크
- [ ] 캠 화면에 스켈레톤 오버레이 표시
- [ ] 실시간 정확도 값이 지속 갱신
- [ ] 가드/스탠스/밸런스 카드 점수 갱신
- [ ] 피드백 문구가 한글로 표시
- [ ] 피드백 박스 색상(초록/노랑/빨강) 상태 변화 확인

## 09) 자동 누적 기록 체크
- [ ] 세션 종료 후 현재 수행치가 자동 증가
- [ ] 달성률이 자동 갱신
- [ ] 세션 기록 목록에 신규 항목 추가
- [ ] 새로고침 후 값이 유지(localStorage)되는지 확인

## 10) 최종 점검 체크
- [ ] 영상 등록 -> 영상 선택 -> 캠 측정 -> 자동 누적 흐름이 끊김 없이 동작
- [ ] 콘솔 치명 오류 없음
- [ ] 모든 주요 문구 한글 출력 확인

---

## 빠른 문제 해결 가이드

### A. 영상이 안 나올 때
- `frontend/assets/videos` 폴더에 파일이 실제로 있는지 확인
- 등록 경로가 `assets/videos/파일명.mp4` 형태인지 확인
- `Ctrl + F5` 강력 새로고침

### B. 캠이 안 켜질 때
- 브라우저 카메라 권한 허용
- 다른 앱(화상회의 등)이 카메라 점유 중인지 확인

### C. 정확도가 안 변할 때
- 캠 화면에 전신이 충분히 보이도록 거리 조정
- 조명/역광 상태 점검
- 비교 영상을 재생 상태로 유지
