# 01. 복서 프로젝트 오늘 채팅 정리

## 01. 작업 목표
- 복서 프로젝트에 `다이어트 복싱` 탭을 추가하고, 관리자 영상 등록/사용자 재생/캠 측정까지 실제 동작 가능한 형태로 확장.
- 초심자 기준으로 사용성이 좋도록 UI/동작 흐름을 단순화.

## 02. 주요 기능 추가 내역
- `frontend/diet.html` 신규 추가 후 프로젝트 내 네비게이션 연결.
- `index.html`, `dashboard.html`, `tutorial.html`, `shop.html`, `admin.html`, `sparring.html`에 `다이어트 복싱` 이동 링크 반영.
- `dashboard.html` 빠른 이동 카드에 `다이어트 복싱` 항목 추가.

## 03. 관리자 영상 등록 기능
- `admin.html`에 `🥗 다이어트 영상` 전용 탭 추가.
- 관리자 입력 항목:
  - 영상 제목
  - 영상 설명
  - 영상 경로
- `파일 선택` 버튼 추가:
  - 파일명 기준으로 `assets/videos/파일명` 자동 입력.
- 등록 데이터는 `localStorage`(`boxer_diet_videos`)에 저장되며 `diet.html`에서 조회 가능.

## 04. 사용자 영상 재생 기능
- `diet.html`에서 관리자 등록 영상을 카드 형태로 표시.
- 사용자가 영상 제목/카드를 클릭하면 하단 플레이어에서 재생.
- 경로 자동 정규화 로직 추가:
  - `frontend/assets/...` -> `assets/...`
  - `C:/...` 절대경로 -> `assets/videos/파일명`
- 재생 실패 시 오류 토스트로 경로 안내.

## 05. UI 개선 사항
- `tutorial.html` 스타일 톤에 맞춰 카드형 UI 적용.
- 영상 섹션을 상단으로 이동.
- `사용자 캠 모드`도 영상 섹션 바로 아래로 이동.
- 한글 깨짐(`보통` 텍스트 등) 일부 보정.

## 06. 목표/진행 관리 개선
- 기존 `추천 루틴`, `영상 정확도 점검` 섹션 제거.
- 사용자가 목표치를 직접 설정 가능:
  - 목표 운동시간(분)
  - 목표 칼로리(kcal)
  - 목표 정확도(%)
- 달성률(진행바) 추가.
- `현재 수행치`는 수동 입력 불가(`readonly`)로 변경.
- 진행값은 캠 모드 세션 종료 시 자동 누적 저장되도록 변경.

## 07. 사용자 캠 모드 기능
- `📷 캠 모드 활성화` / `■ 측정 종료` 버튼 추가.
- 실시간 표시:
  - 정확도
  - 세션 운동 시간
  - 세션 칼로리
- 세션 종료 시 기록 저장(`boxer_diet_sessions`) 및 현재 수행치 자동 누적.

## 08. 정확도 계산 고도화
- `MediaPipe Pose` 적용.
- `TutorialEngine`(`js/tutorial/TutorialEngine.js`) 연결:
  - 튜토리얼과 유사한 방식으로 포즈 정확도 계산.
- 영상 제목 기반 모드 추론:
  - `stance`, `jab`, `straight`, `hook`, `ducking`, `combo`.
- 보조 점수로 사용자/비교영상 각도 유사도 반영.
- 인식 실패 시 모션 기반 폴백 유지.

## 09. 튜토리얼형 피드백 강화
- 사용자 캠 화면 위 스켈레톤 오버레이(canvas) 추가.
- `TutorialEngine.drawColoredSkeleton` 사용.
- 실시간 피드백 박스 추가:
  - 심각도별 색상 표시(`low/medium/high`).
- 체크 카드 추가:
  - 가드
  - 스탠스
  - 밸런스

## 10. 한글화 반영
- 실시간 피드백 문구 한국어 변환 로직 추가.
- `TutorialEngine` 영어 메시지를 한글로 치환해서 표시.

## 11. 오늘 확인/디버깅 내용
- `Video.py`는 서버 포트를 사용하는 앱이 아니라 CLI 스크립트임(포트 충돌 없음).
- `Video.py` 실행 오류 원인 정리:
  - 저장 경로 제한(`Download_Video` 하위만 허용)
  - URL 입력 칸에 파일 경로를 넣은 입력 실수.
- `diet.html` 영상 미재생 이슈 대응:
  - 경로 정규화 + 오류 메시지 개선.

## 12. 현재 결과 요약
- 다이어트 복싱 탭에서
  - 관리자 영상 등록
  - 사용자 영상 재생
  - 캠 모드 측정
  - 자동 누적/달성률
  - 한글 실시간 피드백
  까지 한 흐름으로 동작하도록 구현 완료.
