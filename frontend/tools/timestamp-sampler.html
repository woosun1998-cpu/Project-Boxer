타임스탬프 샘플러

영상 재생 중 M 키를 누르면 현재 시간을 impact_time으로 기록합니다. 기록 후 SQL/JSON으로 바로 복사할 수 있습니다.
이 기능은 무엇을 하나요?
  • 스파링 영상에서 공격 타이밍(impact_time)을 손쉽게 찍어 DB 입력용 데이터로 변환합니다.
  • 마킹한 시점마다 회피 판정값(`dodge_window_ms`, `hitbox_radius` 등)을 함께 저장합니다.
  • 결과를 SQL 또는 JSON으로 만들어 바로 복사할 수 있어, 메타데이터 튜닝 작업 시간을 줄여줍니다.
사용 방법
  1. 영상 파일을 선택하고, 영상 제목/공격 타입을 입력합니다.
  2. 영상 재생 중 공격 시점마다 M 키 또는 현재 시점 마킹 버튼을 누릅니다.
  3. 마킹이 끝나면 SQL 생성 또는 JSON 생성 버튼을 눌러 결과를 만듭니다.
  4. 결과 복사 후 DB 마이그레이션 SQL 또는 문서에 붙여넣어 사용합니다.
현재 시간: 0.000초
참고: `공격 타입`, `판정 형태`, `타겟 부위`, `요구 동작` 값은 DB 저장 규칙상 영문 키(예: `jab`, `circle`, `head`, `slip_side`)를 사용합니다.
