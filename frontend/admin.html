Workflow

DB 사용자 관리와 스파링 공격 타임스탬프 추출을 이 화면에서 바로 처리합니다.

  • 사용자 관리 - `/api/admin/users`를 불러와 tier를 수정합니다.
  • 영상 관리 - 재생 중 M으로 `impact_time`을 찍습니다.
  • 판정 파라미터 - `dodge_window_ms`, `hitbox_radius`, `required_move`, `target_zone`을 조정합니다.

스파링 영상 DB 관리

여기서 영상 파일을 불러오고, 재생 중 M으로 공격 시점을 찍어 타임스탬프를 저장합니다.

0건
공격 타임스탬프 추출 흐름: 영상 재생 → M으로 현재 시점 마킹 → 아래 표에서 impact_time, dodge_window_ms, hitbox_radius, required_move, target_zone 조정 → 저장. 목록의 File Path가 비어 있으면 DB에 경로가 저장되지 않은 상태입니다.
